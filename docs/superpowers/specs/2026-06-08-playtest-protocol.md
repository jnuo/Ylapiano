# Playtest Protocol — Hit-Juice Slice ("does it work?")

**Date:** 2026-06-08
**Owner:** Mei (kid research)
**Tests:** Defne's kill criterion — "a 5-year-old presses the RIGHT key (not any
key), grins, and reopens unprompted on day 3."
**Cohort:** age **5 first and hardest** (Defne's design floor). ≥5 kids age 5.
Below 5 = directional only. Never lump 5/6/7.

## The trap this protocol exists to close

±600ms windows mean a kid can **mash and get rewarded** without learning
note→key. The protocol must distinguish _learned the map_ from _mashed lucky_ —
or the playtest is theater.

## Comprehension — is the right-key DELIBERATE?

1. **Free-play, zero instruction** — does the kid discover "press the key the
   note points at"? Time-to-first-deliberate-hit. (Cooney _Silence is Golden_ —
   count to 10, never hint; "what do you think you should do?")
2. **Thumb-watch** — thumb _aims_ for the correct key (got the map) vs sprays
   (mashing). Hover precedes the face.
3. **Wrong-key rate over time** — instrument right/wrong taps (Marco). Falling
   curve = learning; flat-high = mashing.
4. **"What's the trick to the game?"** (Cooney _Trick of the Game_). "The one
   that matches / where it lands" = got it. "Tap fast" = mashing.
5. **Transfer spot-check** — after play, on the REAL keyboard, no falling note:
   play a note, "can you find this one?" Maps without the cue → early transfer.
   Probes Defne's deferred fun-vs-pedagogy risk. A canary, not a study.

## Affect — the "grin"

- Read the FACE, not words (Cooney _Notice the Nonverbal_). Unprompted smile /
  lean-in on a hit + on the combo escalation.
- Never "did you like it?" (100% yes). Use "show me your favorite part" (replay
  = signal) + "pick three faces" (3rd face = truth).
- Watch the face **on a miss** — does the soft miss keep them calm? Tests
  Diego's no-punish rule directly.

## Retention — day-3 unprompted reopen

- Leave the build with the family 3 days. Parent one-line log: "did your child
  ask to play, unprompted? Y/N, when?"
- **No push notifications** (COPPA ban + contaminates "unprompted").
- **≥3 of 5 reopening = the signal.** Most trusted metric.

## Session shape (age 5), cap ~20 min

3 min warm-up w/ familiar app (baseline neutral face — Cooney _Early
Observations_) · ~12 min free-play, moderator silent · ~5 min debrief (trick /
favorite / three faces / transfer probe). Separate 3-min parent debrief.

## Compliance (non-negotiable)

Child face + voice = biometric personal info (2025 FTC COPPA, full compliance
Apr 2026). Signed parental consent before record · **local-only** capture (iOS
screen record) · **no cloud transcription** · encrypted storage + deletion date ·
kid's own verbal assent ("is it okay if I watch? I'll stop whenever you want").
No consent → no record.

## Founder trap

Your own child is NOT the test: too young for 5–7 **and** you're the parent
(n=1, biased). Recruit **5 age-5 kids you're not the parent of.** If you must
moderate: **don't react** — your gasp/wince contaminates the kid's. Script
neutral phrases, stay silent. Manage the parent before recording (no narration).

## Start NOW, parallel to build

Recruiting 5 families takes lead time. Line them up while the code is written, or
the protocol sits finished with no kids to run it on. (Existing network is valid
— Cooney. Rotate kids; same kid >2–3× = contamination. PlaytestCloud if network
exhausts.)

## Pass / fail

- **Works:** ≥4/5 age-5 show deliberate right-key (falling wrong-key curve +
  "matches" trick answer), unprompted grin on hits, calm on miss, AND ≥3/5
  reopen unprompted by day 3.
- **Broken:** flat-high wrong-key + "tap fast" trick answer = mashing, juice
  taught nothing → fix the note→key _visual_ mapping (Aiko/Diego), not the
  windows.
